# Notes Pro

> Простые заметки и комфортное написание сценариев.

Notes Pro — локальное приложение для заметок, сценариев и больших текстов.  
Без регистрации, без обязательного облака и без лишнего интерфейса.

### ✨ Возможности

- 📝 Удобный редактор текста

- 🔒 Локальное хранение данных
- 🎨 Множество современных тем оформления
- 🔎 Быстрый поиск по заметкам
- 📌 Закрепление важных заметок

### 🚀 Использование

Откройте `https://null1x.github.io/Notes-Pro/` в браузере.

Также Notes Pro можно разместить на **GitHub Pages** и использовать как веб-приложение.

### 🔐 Приватность

Заметки хранятся локально в браузере пользователя.

В текущей версии данные не отправляются на сервер и не требуют регистрации или обязательного облачного аккаунта.

## 🇬🇧 English

### ✨ Features

- 📝 Comfortable text editor
- 💾 Automatic saving
- 🔒 Local data storage
- 🎨 Multiple modern themes
- 🔎 Fast note search
- 📌 Pin important notes
- ↶ Undo and redo history
- 📱 Mobile-friendly interface
- 🌍 Automatic language detection
- 📤 Import and export
- 🗑 Trash with note recovery
- ⛶ Fullscreen mode
- ⌨️ Keyboard shortcuts
- 🖍 Text formatting and highlighting
- ✅ Checklists and lists

### 🚀 Usage

Open `https://null1x.github.io/Notes-Pro/` in your browser.

You can also host Notes Pro using **GitHub Pages** and use it as a web application.

### 🔐 Privacy

Notes are stored locally in the user's browser.

In the current version, data is not sent to a server and no registration or mandatory cloud account is required.
